# Kate Coffie

Senior Software Engineer and Engineering Manager.

## Featured: [Pawroll](https://github.com/kcoffie/dog-boarding)

A dog boarding operations platform that syncs from a booking site with no API, delivers daily rosters unattended and calculates payroll. Developed with Claude Code; I own the requirements, design decisions and quality gates.

I ran it the way I'd run a team: design notes challenged before code is written, a reviewer who didn't write the code, rules enforced by machines, and failures that alert someone instead of passing quietly.

- Thousands of tests, measured by mutation testing rather than test count
- Architecture decision records for the choices that are expensive to undo
- An honest account of production failures and what each one changed
